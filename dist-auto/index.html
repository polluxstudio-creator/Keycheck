How to use the keyboard and mouse tester

Both tests run in the page you are reading, without installation and without permissions.

  1. Open the tester and pick a tab. Start with Keyboard Test for keys or Mouse Test for buttons, wheel and pointer.
  2. Click once anywhere in the page. That gives the page keyboard focus, which is required before the browser reports key presses.
  3. Press the keys you want to check. Every key you press lights up in green and the counters update instantly. Press the Reset test button to start a clean run.
  4. Watch the coverage bar. The unique-key counter grows only when you press a key for the first time, so repeatedly hammering the same key does not fake a 100% coverage.
  5. For the mouse, test inside the box. Move the pointer inside the test area and press each button, scroll the wheel and click twice in a row to check the double-click behaviour.
Important limitation: a browser test can only confirm that the operating system delivers the key and button events to the web page. It cannot detect worn-out switches, an intermittent cable, a failing scroll encoder or a mouse sensor that drifts. Use it as a fast first check, not as a hardware diagnosis.

Quick troubleshooting

The three problems users hit most often, and what they usually mean.

A key does not react at all

If the key never lights up, the browser never received the event. Common causes: another program holds a global shortcut, the key is mapped to a system action, or the keyboard is connected through a Bluetooth link that only forwards some keys.

Full diagnosis →

Double-click does not open anything

The mouse test measures the interval between two clicks. If the interval is much longer than the double-click speed configured in your operating system, the click will be registered as two single clicks — which is exactly what a worn switch often looks like.

Full diagnosis →

The scroll wheel scrolls too fast or jumps

High-resolution scroll wheels report many small events instead of one notch per step. That is normal on modern mice and can be tuned in the system settings, not in the browser.

Frequently asked questions

Short answers to the most common questions. The complete FAQ covers more.

Does the keyboard tester record what I type?

No. Key events are handled inside your browser and only counters are updated. The characters you type are never sent to a server, never stored and never logged. Reloading the page resets the test.

Why does a key stay lit after I release it?

That usually means the browser never received the key-up event, for example because the window lost focus while the key was held. Click on the page or press Reset test to clear the highlighted keys.

Which keys can the browser not detect?

The browser only receives key events that the operating system forwards to it. Several system shortcuts, the Windows key on some setups, media keys and the dedicated button on some laptops are reserved by the operating system and never reach the page.

Does the mouse tester replace a real hardware test?

No. It confirms that the operating system delivers the events to the browser. It cannot detect wear in the switches, an intermittent cable, a failing encoder or a battery that is about to die. Use it as a fast first check.

How do I check a double-click problem?

Open the Mouse Test tab and click twice quickly on the same button. KEYCHECK reports the interval between the two clicks, so you can compare it with the double-click speed configured in your operating system.

Is the tool really free?

Yes. There is no paid tier and no account. When advertising is enabled, this site may show ads from Google AdSense, but the tool itself always stays free and fully functional.
