Keyboard shortcuts cheat sheet

You do not need a hundred shortcuts. You need about twelve that work everywhere, a handful that are specific to your operating system, and the browser ones that save you the most time. This sheet lists exactly those, grouped so you can find them in seconds — and it is written for people who type for a living as much as for people who just want to get the job done faster.

Ctrl + C in a terminal means "cancel", not "copy" — which surprises almost everyone the first time. In a terminal, use Ctrl + Shift + C to copy. Ctrl + R (reverse search) is the shortcut that makes a long history usable: press it, type a few letters, and it finds the command you were looking for.

A printable one-page table

If you want this on paper next to your desk, here is the condensed version — the twelve shortcuts that cover most of what a normal working day needs:

  1. Ctrl / Cmd + Z — undo
  2. Ctrl / Cmd + C / V / X — copy, paste, cut
  3. Ctrl / Cmd + A — select all
  4. Ctrl / Cmd + F — find
  5. Ctrl / Cmd + S — save
  6. Ctrl / Cmd + L — focus the address bar
  7. Ctrl + Shift + T — reopen the closed tab
  8. Alt + Tab / Cmd + Tab — switch window
  9. Win + Space — switch keyboard layout
  10. Win + E / I / R — File Explorer, Settings, Run
  11. Ctrl + Shift + S — screenshot a selection
  12. F12 — developer tools

A neat trick for the ones you keep forgetting: use the Sticky Keys feature of your operating system (Windows: press Shift five times; macOS: Accessibility → Keyboard → Sticky Keys). It lets you press a modifier one at a time, so a two-key shortcut can be typed as two separate presses. It is also a quick way to confirm whether a modifier key is working at all.

Frequently asked questions

Why does Copy and Paste not work in my terminal?

In a terminal, Ctrl + C is the interrupt signal, not copy — it stops the command that is running. Use Ctrl + Shift + C to copy and Ctrl + Shift + V to paste instead. On macOS Terminal the same applies with the Cmd key: Cmd + C copies, because the terminal follows the macOS convention rather than the Linux one.

What is the difference between Ctrl and Cmd on macOS?

They fill the same role: Cmd is the macOS modifier, Ctrl is the Windows and Linux one. A few places use Ctrl on macOS for a different purpose — Ctrl + Cmd + Space opens the emoji picker, for instance — but for everyday editing the substitution is one-to-one. If you switch between a Mac and a PC, thinking in Cmd or Ctrl rather than "the Windows key" makes the transfer painless.

How do I find out what shortcut an application uses?

Almost every application lists its shortcuts in its own menu, usually under Help, or in a Keyboard Shortcuts panel. On Windows, press Alt and the ribbon shows the keyboard equivalent of every button; the same works in Chrome with Alt and in Firefox with Alt. That trick is the fastest way to discover a shortcut without reading anything.

Why does my keyboard type in capital letters?

Almost always a stuck Shift or Caps Lock. Open the keyboard test and look at the modifier row: if Shift or Caps Lock stays highlighted when you are not touching it, that is the cause. Press it once and the problem is over. The tester shows each modifier separately, which makes this visible immediately.

Is there a shortcut to switch between the keyboard and mouse?

On Windows, Win + Tab cycles the open windows and keyboard shortcuts are accepted while it is open. For a genuine hands-free toggle, the accessibility option most people use is Mouse Keys: press the right Alt twice to lock the numeric keypad and move the pointer with it. It is the standard answer for people who find the pointer hard to reach, and the same feature exists on macOS under Accessibility → Pointer Control.
